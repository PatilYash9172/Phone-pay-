# 📊 PhonePe Data Analysis & Power BI Dashboard

An interactive **Power BI dashboard** developed to analyze PhonePe transaction and user data across India. The project focuses on transforming raw datasets into meaningful business insights through data cleaning, analysis, visualization, and interactive reporting.

## 🔍 Key Analysis

* Transaction trends and growth
* State-wise and regional analysis
* User growth and engagement
* Transaction volume and value
* Category-wise performance
* Interactive Power BI visualizations
* Business insights from historical data

## 🛠️ Tools & Technologies

* **Power BI**
* **Microsoft Excel**
* **Data Analysis**
* **Data Visualization**
* **Business Intelligence**

## 📁 Project Structure

* `Dashboard/` – Power BI dashboard file
* `Dataset 1/` – Transaction/user dataset
* `Dataset 2/` – Supporting dataset
* `Images/` – Dashboard preview
* `README.md` – Project documentation

## 🎯 Objective

The main objective of this project is to analyze digital payment data and identify **transaction patterns, regional trends, user behavior, and business opportunities** using Power BI.
